# ハロウィン総柄プリセット

デザイン画面の「背景・柄」→「模様一覧」から5種類の総柄を追加できます。
追加直後から80mm角・すき間なしで繰り返します。「配置済み」→「調整する」で大きさ・位置・回転を変更できます。
封筒の「選択面」では選択した面だけに追加します。ふた付き箱はふた・本体で個別に設定できます。
