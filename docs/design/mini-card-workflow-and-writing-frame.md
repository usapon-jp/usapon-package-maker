# ミニカードの制作・割り付けと記入枠の設計

2026-11-11／今回の実装・公開対象の仕様。実端末での最終的な使い心地は公開後に確認する。

## 決定した方針

- 背景・画像・文字・記入枠まで含めた「完成デザイン」を保存する。
- 完成デザインと「A4の割り付け」を別々に保存し、途中で割り付けを変えてもデザインは保つ。
- 保存したカードを、次回や別の印刷シートから再利用できる。
- サイズ・角度の追加調整は、記入枠に対するもの。カードの仕上がり寸法や画像の操作とは区別する。
- 便箋とミニカードで同じ記入枠の操作を使う。封筒の宛名欄は既存の設定を保つ。

## 制作の流れ

上部に「割り付け → デザイン → 並べる → 保存」の4項目を置く。前後へ自由に移動でき、入力内容を保つ。スマートフォンでは、現在の工程を中心にコンパクトに表示する。

### 1. 割り付け

A4のプレビューと、デザインごとの枚数だけを表示する。最初はA・Bの2種類。必要になったときだけ「＋デザイン」でC以降を追加する。

例：Aを4枚・Bを4枚。91×55mmのカードなら、10枠のうち8枠を使用し、残り2枠は空白にする。3種類ならAを3枚・Bを3枚・Cを2枚など、自由な枚数にする。

「すべて同じ」「種類ごとに枚数」は選択肢を重複させず、Aだけを必要枚数にすれば同じデザインで印刷できる。用紙を超える指定は次ページへ続け、黙って枚数を減らさない。ページ数と合計枚数を表示する。

割り付け変更はいつでも可能。種類を減らすときも完成デザインはライブラリに残し、印刷シートからだけ外す。枠が減って置ききれなくなる場合は次ページへ移し、割り当てを捨てない。

### 2. デザイン

A・B・Cのサムネイルで編集対象を切り替える。各デザインに「新しく作る」「保存したカードから選ぶ」「複製」の入口をまとめる。

既存の「背景／スタンプ／文字／記入欄」の編集タブを使い、常時表示のパネルは1つにする。編集中のカードだけを大きく表示し、A4の小さな枠の中で編集させない。

背景・画像・文字・記入枠をひとまとまりのデザインとして保存する。記入枠だけ、白さだけといった変更もカードのデザインに含める。

### 3. 並べる

完成デザインのサムネイルを選んで、A4の枠をタップすると割り当てられる。ドラッグは補助操作とし、タッチでも確実に操作できるようにする。

枚数指定から自動配置し、その後は1枠ごとに変更できる。「空白」も割り当て先として用意する。手動配置後に枚数を変更する場合は、枠を保って不足分を空白枠へ追加し、再配置で既存の順番を崩すときだけ具体的なプレビューを出す。

同じシート内でAを編集すると、Aを割り当てたすべての枠に反映する。1枠だけ別の見た目にしたい場合はAを複製してBとして編集する。

### 4. 保存

「保存するもの」と「形式」の2項目にまとめる。

- カード1枚：選択した完成デザインをPNG保存。編集用ハンドル、カット線、面名などの案内は含めない。
- A4印刷シート：PDFまたはPNG保存。必要なカット線は初期状態で表示、案内文字は非表示。
- 編集できる状態の作品保存：デザインと割り付けの両方を保持。既存の保存先・アカウントの仕組みに合わせる。

PNGはカードまたは用紙の実寸から原則300dpiで書き出す。PNG印刷の倍率は印刷アプリに依存するので、実寸印刷の入口はPDFを基本にする。PDFとPNGで同じデザイン描画処理を使い、記入枠・透過・回転が一致するようにする。

## 記入枠のコンパクトな操作

「記入欄」タブには「記入枠」のON/OFFを置く。OFFのときは調整を隠す。ONでも画面上には以下だけを置く。

1. 形：四角／角丸／丸／吹き出し。小さな形のプレビュー＋短い名前を4つ並べる。
2. 白さ：0〜100%。0%は透明、100%は白。初期値は現在の見た目を保つ92%。「透明度」の数値の向きによる混乱を避けるため、表示は「白さ」とする。
3. 吹き出しを選んだときだけ「左右反転」「上下反転」の小さなボタンを表示する。押すたびに切り替え、選択状態を保つ。両方を組み合わせてしっぽを四方向へ向けられる。
4. 「大きさ・角度」の折りたたみ。中に大きさと角度の短いスライダーを置く。さらに必要な場合だけ幅・高さ・位置・角度の数値を開く。

白さは白い面だけに適用する。文字・罫線・スタンプは薄くしない。白さ0%でも編集時の選択枠は見えるようにし、印刷には選択枠を出さない。

プレビュー上では枠をタップして選択し、ドラッグで移動。右下のハンドルで大きさ、右上のハンドルで角度を調整する。形の部分だけをつかめるようにし、背景・画像・文字の選択とは競合させない。記入枠が選択中のときだけハンドルを表示する。大きさ・角度の数値入力でも同じ操作ができる。

- 大きさの基本スライダーは縦横比を保つ。幅・高さを別々に変える操作は詳細にまとめる。
- 丸は幅・高さに応じて円または楕円になる。幅と高さを揃えれば真円にできる。
- 吹き出しは初期状態でしっぽを左下に置く。左右反転で右下、上下反転で左上、両方で右上に変えられる。反転専用の詳細パネルは増やさない。
- 反転は記入枠の白い面としっぽだけに適用する。文字・罫線・画像・背景は反転しない。反転しても位置・大きさ・角度・白さを保つ。枠の中心を基準に、枠自身の左右／上下を反転してから回転する。操作ハンドルやボタンの文字は反転しない。
- 形を変更しても反転状態を保持し、吹き出しに戻すと同じ向きに戻る。四角・角丸・丸は対称なので、反転ボタンを隠してUIを簡潔にする。
- 回転は枠の中心を基準にし、しっぽも一緒に回す。15度ごとのスナップを補助に使い、数値では細かく入力できる。
- 「元に戻す」を既存の履歴に統合する。形を変えても白さ・位置・大きさ・角度を保つ。
- 白い記入枠は背景と罫線・スタンプ・文字の間に描画する。枠を動かしても罫線や文字は自動で動かさない。

## 保存と互換性

カードの完成デザインは、背景・画像・スタンプ・文字・記入枠の編集可能データとサムネイルを持つ。印刷シートは用紙、カード寸法、ページごとの枠とデザイン参照を持つ。

ライブラリからシートへ取り込むときは、その時点のデザインをシート内の作業コピーとして取り込む。同じシートの複数枠は同じ作業コピーを参照する。別の保存済みシートを後から変えてしまわない。ライブラリの原本更新は「更新保存」、派生版は「別名で保存」を使う。

旧作品は「角丸・白さ92%・現在と同じ位置とサイズ・角度0度・左右上下の反転なし」に補い、再表示した見た目を保つ。旧ミニカードの画像枚数指定は、各画像＋共通背景・文字・記入枠から完成デザインへ変換する。元の作品は保持し、コピーで移行を確認する。

素材ライブラリと作品保存は既存のアカウント境界を保つ。再利用用のカード一覧はブラウザ内のIndexedDBへアカウント別に保存する。作品全体は既存のクラウド作品JSONにデザインと割り付けを含め、非編集中のカードの画像もアップロード・復元する。新しい公開テーブルやDB権限の変更は行わない。

## 実装時の確認項目

- A4にAを4枚・Bを4枚、A/B/Cを3/3/2枚、Aだけ8枚の各指定を正しく出力する。
- 10枠を超える枚数でも次ページへ続き、保存・再読込後も枚数と手動割り当てを保つ。
- 途中の種類数・枚数変更と、別シートでの再利用で完成デザインを失わない。
- 四角・角丸・丸・吹き出しに対し、白さ0/50/100%、移動、拡大縮小、回転、左右反転、上下反転、両方の反転を確認する。
- 吹き出しを30度回転してから左右／上下反転しても、中心位置と角度を保ち、しっぽだけが期待する向きへ移る。文字・罫線が反転しないこと、保存・復元で向きを保つことを確認する。
- PNGとPDFで透過・形・重なり・クリップ・回転・反転が一致し、選択ハンドルや案内文字が入らない。
- PNGにアップロード画像が反映され、失敗時は完成扱いにせず素材を保つ。
- 320px幅でも4つの形選択と操作が収まり、タップ操作で移動・サイズ・角度が競合しない。
- 旧作品の見た目と既存の箱・封筒の出力を保つ。
